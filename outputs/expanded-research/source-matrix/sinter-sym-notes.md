## 로컬 Windows / RTX 3060 Laptop 6GB 해석

- **로컬 읽기 확인:** `work/gpu-experiment/venv/Lib/site-packages/physicsnemo/__init__.py`에 2.2.2, `torch/version.py`에 2.13.0+cu126과 CUDA12.6가 기록되어 있다. 경로의 bytecode 표기는 CPython3.13이다. 단순 디렉터리 확인에서 tensorflow/torch_scatter/dgl/apex 패키지 폴더가 발견되지 않았다. 이는 이 조사 시점의 파일 관찰이며 import 성공 테스트는 아니다.
- **사실:** 현행 core pyproject는 Python>=3.11,<3.15, Torch>=2.13이다. `[gnns]`는 torch_scatter 외 torch_geometric/torch_sparse/torch_cluster도 추가한다. VFGN만 쓰기 위해 전체 extra가 모두 필요한 것은 모델 imports로 입증되지 않는다. `[cu12]`는 현 설정에서 CUDA12.9 index를 선택한다. 기존 cu126 환경에 extra를 무심코 적용하지 않는다. [pyproject L13–28](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/pyproject.toml#L13-L28), [L151–172](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/pyproject.toml#L151-L172), [L358–370](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/pyproject.toml#L358-L370).
- **미검증:** 위 Windows/Torch/CUDA/Python 조합에서 torch_scatter와 TensorFlow wheel을 확보하여 전체 추론하는 과정. 공식 README의 시험 wheel은 Linux/Python3.11이므로 이 로컬 조합의 검증 증거가 아니다.
- **추정:** 6GB에서는 노드 수/edge 수가 용량을 좌우한다. latent128 float32의 node+edge 활성값 한 벌만 `512*(N+E)` bytes이며 10개 message-passing 중간값·MLP·gradient·optimizer·TF CPU pipeline을 추가로 고려해야 한다. 모델은 processor를 checkpoint하지만 이것이 원 논문 크기 전체의 6GB 학습을 보장하지 않는다. [model architecture L753–756](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/physicsnemo/models/vfgn/graph_network_modules.py#L753-L756), [checkpoint L670–672](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/physicsnemo/models/vfgn/graph_network_modules.py#L670-L672).
- **사실:** 논문은 다른 해상도에서 수천~수십만 노드를 다루며 NVIDIA GPU로 실험했다고만 이 부분에서 적는다. 해당 논문의 시간/오차를 RTX3060 Laptop 결과로 옮겨 쓰면 안 된다. **미검증:** 이 장치에서 최대 노드/edge수, 메모리 사용량, 속도, 원 논문 정확도 재현. [paper IV / Table II](https://arxiv.org/html/2404.11753v1#S4.SS2).
- **사실:** `inference.py`는 선택 장치 또는 CPU를 사용하지만 eval `train.Test()`에는 나중에 `setMessagePassingDevices(['cuda:0'])`가 하드코딩되어 있다. CPU-only eval 경로까지 일반 지원으로 주장하지 않는다. [inference L109–111](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/additive_manufacturing/sintering_physics/inference.py#L109-L111), [test L558–565](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/additive_manufacturing/sintering_physics/train.py#L558-L565).

**사실:** current core 구조 예제는 `examples/tcad/fp_ddm/run_elasticity.py`이다.
