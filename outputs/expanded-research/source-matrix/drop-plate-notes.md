## 실행자가 먼저 선택할 경로

1. **작은 공개 구조변형 재현은 deforming_plate의 HybridMeshGraphNet.** 노드 입력3, edge8, 출력4이며 DeepMind 공개 TFRecord를 사용한다. 기본 학습은 한 단계 supervised, 추론은 이전 예측 위치를 되먹이는 autoregressive 방식이다. 원본 설정은 batch1/1000 trajectories/200 steps/30 epochs로, 작은 검증 실행에서는 sample/steps를 명시적으로 축소해야 한다. [설정 L23–44](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/conf/config.yaml#L23-L44), [모델 생성 L136–145](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/train.py#L136-L145), [추론 L139–177](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/inference.py#L139-L177).
2. **낙하 충격 및 Von Mises stress는 drop_test의 GeoTransolver one-shot이 제공된 유일한 완성 실험 설정.** 입력은 초기 xyz와 8개 시나리오 전역변수, 출력은 99단계 × (xyz3+stress1)=396. 다만 준비된 VTU 학습 데이터의 공식 다운로드 URL을 이 예제에서 찾지 못했고 모든 데이터 경로는 `???`다. [실험 설정 L29–70](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/conf/drop_test_geotransolver_oneshot.yaml#L29-L70), [다른 설정의 미검증 명시 L206–220](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/README.md#L206-L220).
3. **현 PhysicsNeMo 2.2.2에서 drop_test main 설정은 그대로 호환되지 않는다.** Geo 설정의 `activation_checkpointing`, `checkpointing_ratio`, `activation_checkpointing_components` 3개 키(L29–31)를 설치된 2.2.2 GeoTransolver 생성자가 받지 않는다. 별도 호환 설정에서 해당 키를 제거하고 수정 내역을 보존하는 경로가 필요하다. 이는 소스 비교에 따른 TypeError 예상이며 이 조사에서는 instantiate 실행하지 않았다. [main Geo 설정](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/conf/model/geotransolver_one_shot.yaml#L17-L33), [main Geo 생성자 L416–443](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/physicsnemo/models/geotransolver/geotransolver.py#L416-L443). 설치소스 비교 경로는 아래 환경 절에 기록했다.

## drop_test: feature와 예측 목표

- 초기 노드 좌표 `[N,3]`; 기본 static/dynamic node features는 비어 있다. 전역조건은 `e_scale_mat1,4,5,8,9`와 `rwall_orientation_rx,ry,rz`, 합8이며 정규화되지 않는다. 각 run ID는 VTU filename stem과 JSON key가 일치해야 한다. [설정 L51–70](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/conf/drop_test_geotransolver_oneshot.yaml#L51-L70), [JSON L251–275](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/README.md#L251-L275), [TODO L329–333](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/README.md#L329-L333).
- Reader는 tet/hex UnstructuredGrid VTU 하나를 run 하나로 읽고, `mesh.points`와 `displacement_t*`로 position trajectory를 구성한다. training target은 **정규화된 위치**, one-shot raw 예측의 xyz에 초기 정규화 좌표를 더한다. 변위는 예측 위치−초기 위치로 산출할 수 있다. [reader 설명 L277–286](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/README.md#L277-L286), [normalization L363–395](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/datapipe.py#L363-L395), [rollout add coords L74–87](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/rollout.py#L74-L87).
- `Von_Mises` target은 log1p(clamped nonnegative) 뒤 train mean/std 정규화하며 inference는 denormalize→expm1한다. inference VTU는 predicted/exact/difference fields를 저장한다. 변형률·damage/failure/contact force는 기본 출력에 없다. [target 처리 L311–340](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/datapipe.py#L311-L340), [inference inverse L77–101](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/inference.py#L77-L101).
- graph 대안은 초기 좌표의 relative xyz+distance4, coalesced 양방향 mesh edges+self loops. 기본 Geo point-cloud 경로는 mesh connectivity를 모델 graph로 사용하지 않는다. [graph L679–695](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/datapipe.py#L679-L695), [point cloud L721–726](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/drop_test/datapipe.py#L721-L726).

## deforming_plate: feature·전처리·추론의 정확한 의미

- Mesh topology는 trajectory 내 고정이다. Dataset가 첫 timestep cells로 한 adjacency만 구성하므로 adaptive remeshing에 그대로 사용할 수 없다. tet당 6 edges→undirected/coalesce. [dataset 주의 L34–40](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/deforming_plate_dataset.py#L34-L40), [adjacency L280–303](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/deforming_plate_dataset.py#L280-L303).
- Node x는 현재 xyz가 아니라 node_type `{0,1,3}`을 3class one-hot으로 만든 값이다. geometry는 edge feature에 들어간다. 기본 node target은 `world_pos[t+1]−world_pos[t]` xyz와 `stress[t+1]` scalar. 코드명 `velocity`는 **dt로 나누지 않은 step displacement**다. TFRecord stress의 물리 단위와 stress invariant 종류는 이 loader만으로 확정하지 않는다. [node target L144–152, L186–200](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/deforming_plate_dataset.py#L144-L200), [one-hot/diff L340–363](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/deforming_plate_dataset.py#L340-L363).
- Static mesh edge=reference `mesh_pos` relative xyz+norm4. 매 step helper가 current world relative xyz+norm4를 붙여 mesh edge8로 만든다. world/contact edges는 radius0.03 내 가까운 node쌍에서 기존 mesh edge와 self-loop를 제외하며, 상대 world xyz+norm4를 2회 반복하여8로 만든다. world edge가 없으면 ValueError다. [static4 L305–314](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/deforming_plate_dataset.py#L305-L314), [helper L23–97](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/helpers.py#L23-L97).
- `preprocessor.py`는 training split의 모든 요청 trajectory를 dataset에 올리고 step마다 graph/world edges를 만든 뒤 `sample_00000.pt` 리스트에 저장한다. 학습 LazyTimeStepDataset는 각 step 요청마다 해당 sample 파일 전체를 CPU에 load한다. I/O와 전처리 보관량이 크므로 전체1000×200을 처음부터 실행할 이유는 없다. [preprocessor L40–76](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/preprocessor.py#L40-L76), [lazy dataset L72–97](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/train.py#L72-L97).
- Train data에는 node type0 위치에 Gaussian noise std0.003을 한 번 넣고 increment target에서 빼며, stress와 increment는 각각 train 통계로 정규화한다. [noise L154–184](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/deforming_plate_dataset.py#L154-L184), [noise helper L373–379](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/deforming_plate_dataset.py#L373-L379).
- Rollout는 xyz increment만 역정규화·적분하고 type0만 예측 이동, type1 object와 type3 clamped에는 **GT의 next position boundary condition**을 넣는다. stress4번째 output은 predict() 결과에 보존하지 않는다. 따라서 기본 inference.py로 응력 그래프를 생성했다고 보고하면 안 된다. [inference L133–181](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/inference.py#L133-L181).
- 기본 `viz_vars: [disp_mag]`는 실제 코드에서 `norm(world_pos)`를 표시한다. 초기좌표를 뺀 displacement magnitude가 아니다. 올바른 변위 오차/영상에는 sample reference 위치를 빼야 한다. [viz 코드 L188–205](https://github.com/NVIDIA/physicsnemo/blob/11685edb3ec1fb6f25665e96cf7a8c4d11a23f16/examples/structural_mechanics/deforming_plate/inference.py#L188-L205).
