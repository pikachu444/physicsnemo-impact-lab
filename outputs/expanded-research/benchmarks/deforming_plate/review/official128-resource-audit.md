# 공식 용량 128/15 자원 측정의 독립 검산

보존된 실제 probe의 완료 상태, 소스·설정·측정·분할 해시, 설정과 기록의 일치, 학습 전용 정규화, 자원 수치와 시간 가이드 9개 산식을 확인했습니다. 모델을 다시 실행하지 않았습니다. 프레임워크 없이 생성자 소스의 Linear와 LayerNorm 파라미터를 정수로 합산해 **3,605,636개**를 독립 확인했습니다. 모든 hidden은 128, processor는 15, activation checkpoint segments는 공식 기본값 0입니다.

- 실제 Adam update: 준비 2회 + 측정 3회, 측정 평균 **0.415859초**.
- graph 준비·forward·출력 전달: 평균 **0.160416초**, 미리 만든 입력의 pure forward: **0.136373초**. 각각 별도로 준비 2회 후 3회 측정했습니다.
- import/setup 포함 전체 경과: **45.403844초**. 첫 cold update 개별 시간은 저장되지 않아 알 수 없습니다.
- 선택한 학습 형상: 1,488절점, 시작 단계의 유향 mesh/world edge 합계 **60,298개**. 단일 형상에 대한 짧은 측정입니다.
- GPU tensor allocated peak: **3,176,932,864 B**, allocator reserved peak: **3,498,049,536 B**. 다른 프로세스와 일부 드라이버 메모리는 포함하지 않습니다.
- 20ms sampled RSS와 Windows peak working set: **1,644,982,272 B**. Windows peak pagefile **6,714,429,440 B**는 private committed/virtual 사용량이며 물리 RSS나 실제 디스크 swap 사용량과 동일하지 않습니다. sampled host available 최소는 **268,742,656 B**였습니다.

시간 가이드의 학습 update 수는 `32 × anchor × epoch`, epoch별 검증은 `epoch × 6 × 12`회, 학습 후 검증/최종평가는 `(6+6) × 399 × 2 = 9,576`회로 독립 재계산했습니다. 마지막 항의 proxy는 **25.602분**이며 전체 후보 합계는 **35.437–171.399분**입니다. 이 수치는 I/O·압축 해제·저장·변형률·그림·페이징과 형상별 시간 변동을 제외한 산술 추정입니다. 학습 cap 선택이나 전체 wall-clock 보장은 아닙니다.

probe는 학습 형상의 일부 update 이후 반환했고 정확도 학습·평가 파일은 생성하지 않았습니다. 새 최종평가 예측을 수행하지 않았으며, raw 파일 해시 접근은 정확도 평가와 구분합니다. 종료 확인 기록에는 probe 프로세스가 사라졌다고 남아 있습니다. 이 감사는 저장 기록과 소스의 일치 확인이며 GPU를 재실행한 독립 재현은 아닙니다.
