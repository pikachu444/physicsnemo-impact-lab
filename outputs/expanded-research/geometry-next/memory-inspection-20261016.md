# 현재 PC의 RAM 사용 확인

2026-10-16 08:40 KST의 읽기 전용 조사다. 총 RAM은 **15.685GiB**, 당시 사용 가능한 RAM은 **0.933GiB**였다. 직전 관측에서는 0.71GiB였으므로 값은 계속 변한다.

| 앱 / 프로세스 그룹 | 프로세스 수 | 전용 상주 RAM 합계 |
|---|---:|---:|
| ChatGPT.exe | 22 | 4,590.0MiB, 약 4.48GiB |
| codex.exe | 4 | 1,591.7MiB, 약 1.55GiB |
| vmmemWSL | 1 | 628.6MiB |

`Win32_PerfFormattedData_PerfProc_Process.WorkingSetPrivate`를 사용했다. 공유 페이지가 중복될 수 있는 일반 working set이나 가상 메모리 예약량을 합한 값이 아니다. 표 합계가 PC 전체 메모리 사용량을 설명하지는 않는다. OS·커널·캐시와 다른 앱도 RAM을 쓴다.

**확인된 것:** 큰 비중을 차지하는 것은 ChatGPT·Codex 앱이다. 다른 로컬 프로젝트의 활성 작업 세션도 하나 확인했다. 이번 연구 폴더를 사용하는 학습·FEM 프로세스는 현재 확인되지 않았다. 연구에서 남겨 둔 학습 프로세스를 종료하여 확보할 수 있는 RAM은 이번 검사에서 찾지 못했다.

**확인되지 않은 것:** 프로세스 RAM을 개별 채팅이나 작업 세션에 정확히 귀속하지 못했다. 여러 프로세스가 있다는 이유로 그 수만큼 작업이 실행 중이라고 판단할 수 없으며, 사용하지 않는 앱이라는 증거도 아니다.

어떤 앱·프로세스·다른 세션·WSL도 종료하지 않았다. 개별 명령줄·창 제목·다른 프로젝트의 식별 정보는 공개 기록에서 제외했다. [관측 수치와 측정 방법](memory-inspection-20261016.json)

현재 여유 RAM으로 새 복잡 모델 학습을 시작하지 않았다. 문제 구성과 표준 라이브러리만 사용하는 설정 검사를 진행한다. 필요한 학습 RAM·VRAM은 실제 데이터 한 조건과 모델별 자원 검사 뒤에 정하며, 아직 대여 GPU나 비용을 확정하지 않았다.
