# 복잡 형상 예측: 문제 구성

**검증할 질문은 ‘초기 형상이 달라지면 구조 응답의 차이를 예측할 수 있는가’다.** 하중·재료만 바꾸는 시험으로 이 질문을 대신하지 않는다. 이 폴더는 후속 문제 구성이다. 새 복잡 형상의 모델 학습·추론·정확도 결과는 아직 없다.

## 대상과 예측 문제

우선 후보는 [SHIFT-Crash](https://huggingface.co/datasets/luminary-shift/SHIFT-Crash)의 차량 정면 충돌이다. 공개 카드에는 전체 Yaris 조립체의 형상 변경 4축, 표면 376,593절점, 120ms 동안 13시점의 응답이 설명되어 있다. 세탁기·TV의 검증 결과로 확대하지 않는다.

| 항목 | 구성 |
|---|---|
| 바꾸는 것 | front rails, cabin length, car width, roof height의 초기 기하형상 |
| 고정해야 하는 것 | 충돌 속도·벽 조건·재료·rail 두께와 항복강도; 실제 params에서 동일 재료 묶음 존재 여부부터 확인 |
| 예측 입력 | 변형 전 좌표·필요한 연결 관계·부품 구분, 알려진 재료·경계조건, 예측 시각 |
| 예측 출력 | xyz 변위, von Mises 응력, 등가소성변형률(EPSP) |
| 입력에서 제외 | 예측하려는 시각의 정답 변형 좌표·응력·변형률 |
| 형상 분리 | 같은 형상의 모든 시점·재료 변형은 한 분할에 묶고, 평가 형상을 학습에서 제외 |
| 비교 기준 | 동일 평가 형상·물리 위치·시각에서 물리 단위 오차, 병진 제거 변위, 부품별·국부 고응답 영역 오차, RAM·VRAM·시간 |

EPSP는 총변형률과 다르다. 현재 확인한 공개 카드에는 원 총변형률 라벨이 없으므로 총변형률 검증을 완료할 수 있다고 약속하지 않는다. 스트레스 텐서의 추가 성분도 실제 파일 검사 뒤 채택한다.

정확히 같은 재료·두께의 형상 묶음이 없다면 이 자료만으로 형상 효과를 분리했다는 결론을 내리지 않는다. 동일 연결 관계의 morph 형상에 성공해도 부품 수·접합·구멍·접촉 위상이 달라지는 제품까지 입증한 것은 아니다.

## 알고리즘과 메시 비교

| 비교 | 조건과 판단 범위 |
|---|---|
| 알고리즘 | 기존에 실행한 Transolver, FLARE, GeoTransolver GALE/GALE_FA, MeshGraphNet, FIGConvUNet의 6설정·5계열을 후보로 둔다. 새 데이터 로더·입출력 연결과 자원 검사가 각 모델의 실행 전 조건이다. |
| 형상 일반화 | 학습에서 제외한 초기 형상의 응답을 예측한다. 모든 형상을 개별 bounding box로 같은 크기로 정규화하여 치수 차이를 없애지 않는다. |
| AI 입력 해상도 | 같은 FEM 정답에 대해 AI 입력 점·그래프 해상도를 바꾸고 공통 물리 위치에서 평가한다. 그래프 모델에는 유효한 그래프 재구성이 필요하다. 단순 임의 절점 삭제로 처리하지 않는다. |
| 실제 FEM 메시 영향 | 같은 물리 형상을 다른 FEM 메시로 다시 해석하여 기준 해의 수렴과 AI 오차를 함께 비교한다. SHIFT의 morph 데이터만으로는 이 시험을 충족하지 못한다. 별도 데이터 생성·매핑이 필요하다. |

학습량·조건 수·GPU 구성·최종 모델은 아직 확정하지 않았다. 실제 한 조건의 필드·연결 관계와 모델별 자원을 확인한 뒤 비교 가능한 예산을 정한다. 시간 조건부 직접 예측과 자기회귀 자유 예측은 학습·평가 방식까지 구분하여 비교한다.
